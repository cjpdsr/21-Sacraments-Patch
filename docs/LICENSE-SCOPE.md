The repository contains several origins of material. A file's location alone
does not make its entire contents the original work of bigbullet3.

| Material | Applicable terms |
| --- | --- |
| Inherited Ishimura code, including portions of `src/silenttraverse.cpp` and other derived files | Luke's unchanged `LICENSE` / `src/LICENSE` |
| Original SH2-specific additions for which bigbullet3 holds the relevant rights, including the RT budget adaptation | `CONTRIBUTIONS-LICENSE.txt`, alongside upstream terms where combined |
| Original project documentation and research write-ups for which bigbullet3 holds the relevant rights | `CONTRIBUTIONS-LICENSE.txt`; quoted or inherited material retains its own rights |
| MinHook under `src/third_party/minhook/` | Its unchanged `LICENSE.txt` and source notices |
| Other authors' future contributions | Their applicable license and contribution agreement; ownership is not automatically transferred |

The project-specific terms allow private noncommercial study, builds and
modification. **External redistribution—including modified releases or ports
containing covered contributions—and commercial use require prior written
permission.** Approved reuse must credit bigbullet3 and retain the upstream credit
where applicable. A GitHub fork is covered only to the extent allowed by GitHub's
platform terms; it is not blanket permission to publish an external release.

General techniques, public facts and independently written code are not claimed
as exclusive property by this license. Research data do not gain copyright merely
because they appear in a licensed repository.

This is a prospective license for covered contributions accompanying it. It does
not revoke previously granted permissions, change Luke's license, or relicense
third-party material. The source snapshot and original upstream license remain
unchanged; the provenance hashes describe the imported public release source.
